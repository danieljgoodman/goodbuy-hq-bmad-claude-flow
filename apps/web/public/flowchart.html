Data Flow Architecture

  • Frontend: React with Next.js for SSR/SSG
  • State: Zustand for client state, Clerk for auth
  • API: Next.js API routes with middleware
  • Database: Supabase PostgreSQL
  • Caching: Redis for performance
  • External: Clerk auth, Claude AI, Stripe payments
